# 个人理财管理系统 — 命令行演示程序

## 环境准备

```bash
cd demo/
pip install -r requirements.txt
```

## 数据库配置

在运行程序前，修改 `finance_cli.py` 中的数据库连接参数：

```python
DB_CONFIG = {
    'host': 'localhost',       # GaussDB 主机地址
    'port': 5432,              # 端口
    'dbname': 'finance_db',    # 数据库名
    'user': 'gaussuser',       # 用户名
    'password': 'your_password' # 密码
}
```

## 运行

```bash
python finance_cli.py
```

## 注意事项

1. 运行前确保数据库已创建且 SQL 脚本（02~07）已全部执行
2. 或直接执行 `sql/09_all_in_one.sql` 一键初始化
3. 转账操作会自动维护账户余额
4. 所有金额输入均为正数（支出/收入由菜单选择决定方向）
